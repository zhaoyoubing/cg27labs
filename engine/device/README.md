# The Render Hardware Interface (RHI) directory

## Overview
The render hardware interface (RHI) to Graphics APIs/hardware abstractions.

Commonly named as rhi, sometimes as backend in other engines.

Production game engine have different subfolders such as OpenGL, Vulkan, D3d12

In the academic year of 26/27, we only focus on OpenGL
